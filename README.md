# Портфолио видеографа

Страницы: главная (имя, о себе, контакты) → Видео → Фото → категория с мозаикой фото.
Сайт статический, сборка не нужна. Содержимое лежит в папке content:
site.json (главная и контакты), video.json (видео), photo.json (категории фото).
Всё это редактируется через админку по адресу `адрес-сайта/admin/`.

## Посмотреть у себя на компьютере
В папке сайта (где index.html) открой терминал и выполни:

    py -m http.server 8000 --bind 127.0.0.1

Затем открой http://localhost:8000

## Как добавлять
- Видео: Сайт → Видео → Добавить видео. Ссылка на YouTube или Vimeo, тип (Репортаж, Промо…), год.
- Фото: Сайт → Фото → Добавить категорию, потом внутри «Добавить фото» нужное число раз.
  Фото лучше сжимать до ширины 1600–2000 px, формат JPG.
- Главная и контакты: Сайт → Главная и контакты.
- Порядок элементов меняется перетаскиванием. Не забывай нажимать Publish.
- Примеры (images/sample) можно удалить в админке вместе с примерными записями.
